AI와 함께
홈페이지 만들기

HTML · CSS3 · JavaScript를 배운 뒤, AI에게 초안을 맡기고
제가 직접 읽고 고치는 방식으로 웹페이지를 만들어 봤어요.

AI는 제작 속도를 높이는 도구예요.

이번 수업에서
배운 4가지

1

AI 제작 방식 이해

텍스트, 캡처, 그림판 스케치, 손그림 등 입력 방식을 비교했어요.

2

HTML·CSS·JS와 연결

AI 결과를 태그 구조, CSS 선택자, JS 이벤트 관점에서 점검했어요.

3

프롬프트 작성법

한 번에 완성본을 요구하지 않고 구조 → 디자인 → 기능 → 수정 순서로 요청해요.

4

윤리와 저작권

캡처는 참고용으로만 쓰고, 실제 사이트를 그대로 복제하지 않아요.

AI로 홈페이지를
만드는 6가지 방법

같은 목표라도 AI에게 주는 입력 자료에 따라 만드는 방식이 달라져요.

방법 1 · 기본 방식

텍스트 프롬프트로 만들기

만들고 싶은 홈페이지의 목적과 구성을 글로 정리한 뒤 AI에게 요청해요.

  • 목적, 메뉴, 색상, 기능을 구체적으로 적기
  • header, section, footer 같은 태그를 지정하기
  • HTML → CSS → JavaScript 순서로 나누어 요청하기

방법 2 · 이미지 입력

웹사이트 캡처본 참고하기

마음에 드는 화면을 캡처해서 보여주면, 구성과 분위기를 참고한 초안을 만들 수 있어요.

  • 캡처: 참고하고 싶은 화면 저장
  • 구조 분석: 메뉴, 본문, 카드, 버튼 찾기
  • 재구성: 복제가 아닌 비슷한 구조의 새 페이지

실제 사이트의 디자인, 이미지, 문구를 그대로 베끼면 안 돼요.

방법 3 · 스케치 입력

그림판·파워포인트 시안으로 만들기

그림을 잘 그릴 필요는 없어요. 박스만 배치해도 AI가 레이아웃을 해석해요.

  • 제목, 메뉴, 카드, 이미지 영역을 사각형으로 표시
  • "자기소개", "프로젝트"처럼 영역 이름 적기
  • 그림을 첨부하고 HTML/CSS/JS 변환 요청

방법 4 · 와이어프레임

손그림 와이어프레임으로 만들기

종이에 대충 그린 화면도 설계도가 돼요. 색보다 "어디에 무엇이 들어가는지"가 중요해요.

  • 레이아웃 중심: 박스 위치와 영역 구성
  • 내 아이디어 반영: AI는 내 설계를 구현할 뿐
  • 코드 수정 학습: 배치, 여백, 정렬을 직접 조정

방법 5 · 코드 개선

기존 코드 수정·확장하기

이미 작성한 코드의 문제를 찾고 개선하는 데도 AI를 쓸 수 있어요.

  • 어떤 부분이 오류인지 먼저 설명해 달라고 하기
  • CSS 선택자와 JS 이벤트 연결을 특히 확인
  • 고친 결과를 그대로 믿지 말고 직접 실행해 보기

방법 6 · 도구 활용

도구별 미리보기 활용하기

Canvas, 웹 기반 에디터, VS Code 보조 도구로 결과를 바로 확인해요.

  • 생성된 코드를 바로 브라우저에서 열어보기
  • 어색한 부분을 눈으로 확인하고 다시 요청
  • 최종 파일은 직접 정리해서 저장

사용한 방법

          
방법 1(텍스트 프롬프트)로 시작했어요. 수업 자료 내용을 정리해 넣고, "토스 앱처럼 흰 배경·큰 제목·둥근 카드" 스타일로 요청했어요.

        

        

          
요청 순서

          
① HTML 구조(header, nav, main, section, footer) → ② CSS 카드형 레이아웃 → ③ 탭·프롬프트 생성기·체크리스트 JavaScript 기능 순서로 나누어 요청했어요.

        

        

          
직접 확인한 부분

          
브라우저와 모바일 폭에서 열어 보고, 탭 버튼의 data-tab 값과 패널의 data-panel 값이 맞게 연결되는지 확인했어요.

        

        

          
지켜야 할 점

          
토스의 로고, 이미지, 문구는 쓰지 않고 분위기(색감·여백·글자 크기)만 참고했어요.
